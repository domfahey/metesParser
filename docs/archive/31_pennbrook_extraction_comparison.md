## Bugs Found & Fixed During This Analysis

### Bug #42: Curve parser only matches "arc length", not "arc distance"
- **Status:** Fixed (commit `d99a592`)
- **Impact:** Curve calls using "AN ARC DISTANCE OF X FEET" were silently dropped
- **Fix:** Updated regex to `arc\s+(?:length|distance)\s+(?:of\s+)?`

### Temperature=0 for OpenAI
- **Status:** Fixed (commit `8d40e7d`)
- **Impact:** GPT-4.1 produced different results every run
- **Fix:** Added `"temperature": 0` to both OpenAI generate methods

### Model Upgrades
- OpenAI: `gpt-4.1` -> `gpt-5.2` (commit `d64a7e8`)
