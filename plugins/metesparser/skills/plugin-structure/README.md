# plugin-structure

Organize portable Claude plugin components and validate their discovery.

## Example request

> Organize this plugin's skills and fix its manifest paths.

## Inputs and outputs

**Inputs:** The existing plugin directory and the requested component or layout change.

**Outputs:** A focused layout/manifest proposal or authorized edit, plus validation evidence. This is a development guide, not a boundary review.
