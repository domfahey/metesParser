# review-deed

Keep a deed-specific entrypoint to the shared metes-and-bounds review workflow.

## Example request

> Review this deed and check the closure of the described parcel.

## Inputs and outputs

**Inputs:** A deed or its text, with the target parcel identified when multiple descriptions are present.

**Outputs:** The shared review workflow's source-selection record and deterministic results. This skill does not implement a separate parser.
