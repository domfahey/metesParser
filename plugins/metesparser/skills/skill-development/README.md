# skill-development

Create or improve focused plugin skills and their supporting resources.

## Example request

> Add a skill for reviewing supplied boundary calls, reusing the existing verifier.

## Inputs and outputs

**Inputs:** Concrete task examples, selection boundaries, and the existing plugin resources.

**Outputs:** A focused SKILL.md, human-facing README, needed references or helpers, changelog entry, and explicit validation evidence. Search for an existing skill before adding one.
