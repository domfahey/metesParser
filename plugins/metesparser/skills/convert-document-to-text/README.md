# convert-document-to-text

Convert source documents into text using Claude's native reading.

## Example request

> Convert this survey image to text, preserving its bearings and distances.

## Inputs and outputs

**Inputs:** An attached PDF, scan, image, or another source supported by the current Claude session.

**Outputs:** `source-text.txt`, a page map, and a source-acquisition record with reading gaps and uncertainties.
