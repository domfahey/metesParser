# extract-metes-and-bounds

Locate and preserve the intended boundary description inside any document's text.

## Example request

> Find the new tract's metes-and-bounds description in this report, including its continuation and exceptions.

## Inputs and outputs

**Inputs:** Complete prepared source text, available page references, and the intended tract if more than one is described.

**Outputs:** A separate verbatim description file for each candidate and a description-selection record. Missing exhibits or ambiguous tracts require clarification.
