# plugin-settings

Design or maintain validated project-local plugin configuration.

## Example request

> Add an output-directory default for this project's plugin reviews.

## Inputs and outputs

**Inputs:** The plugin's existing settings schema, reader, and requested configurable behavior.

**Outputs:** A validated schema/reader change or project settings guidance, with documented defaults, CLI precedence, and reload behavior. Verification rules remain enforced.
