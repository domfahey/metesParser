# review-metes-and-bounds

Locate the intended description first, then check its geometry deterministically.

## Example request

> Check whether the boundary in this attached survey closes.

## Inputs and outputs

**Inputs:** A source document/image, prepared text, an isolated description, or explicitly selected structured boundary calls.

**Outputs:** Source-selection context plus the deterministic review's status, calls, verification, audit, and artifact paths. Material source gaps prevent a verified result.
