# Description comparison limits

`mp_models.comparison.ComparisonRequest` is the authoritative runtime input contract. The packaged [request JSON schema](../skills/compare-descriptions/references/comparison-request.schema.json) is generated from that model; cross-field identities and geometric rules are additionally enforced by the runtime. The [synthetic request](../skills/compare-descriptions/references/comparison-example.json) demonstrates two source-linked `PlotRequest` descriptions, explicit pair IDs and orientation, unknown-but-honestly-labeled basis identity, and sourced tolerances. It is an example only; do not reuse its synthetic tolerance as a real criterion.

Geometric comparison is meaningful only with supported straight calls, known compatible linear units/foot definitions, compatible bearing basis, and any necessary explicitly sourced placement/rigid transform. A label alone does not establish basis identity. Unknown basis may still allow textual/structural differences; vector direction/position remains separately `not_comparable` or `unavailable` with a reason. Do not infer rotation, translation, scale, or coincidence from matching shapes.

The deterministic structural pass uses unique exact anchors when available, detects reorder/change/unmatched sequence items, and proposes contiguous split/merge candidates. Repeated patterns remain ambiguous. These are tentative correspondences, not established shared boundaries or definitive omissions. Curves and relative constraints are unsupported geometrically. Source quotes and original call payloads remain separate from numerical normalization.

The CLI retains exact request bytes and a versioned result/manifest in a new directory. Its top-level `needs_review`/exit 1 is advisory, including when values agree; invalid input or output path returns `error`/exit 2. Component outcomes say which of the supplied criteria agree, differ, or cannot be compared. No result changes canonical verification tolerance, findings, record values, source-reading status, or verified-export eligibility. Comparison-output display must preserve the same boundaries.
